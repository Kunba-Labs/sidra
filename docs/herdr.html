herdr

Patch herdr for Sidra

Sidra shows herdr's tabs as chips, so herdr's own tab row shows them twice. A one-line patch to the herdr client hides that row. The patch is optional.

Let your coding agent do it

On the machine that runs herdr, give your agent (Claude Code, Codex or similar) this prompt:

Read https://kunba-labs.github.io/sidra/herdr.md and follow it.

The instructions are plain Markdown at herdr.md. The agent builds the patched client, checks it, and reports the result to you.

Do it yourself

You need herdr, git and cargo. Run these as the user Sidra signs in as:

curl -fsSL -o /tmp/herdr-client.sh https://raw.githubusercontent.com/Kunba-Labs/sidra/main/tools/herdr-client.sh
sh /tmp/herdr-client.sh
~/.local/share/sidra/herdr-client --version
herdr --version

The last two lines must print the same version. Then close the herdr tab in Sidra and open it again.

Run the script again after each herdr upgrade. Until then, Sidra uses the stock herdr client.

The change

In herdr's src/client/shell/config.rs, the tab row stays hidden while SIDRA_HIDE_TAB_BAR is set:

let show_tab_bar = rows > 1 && std::env::var_os("SIDRA_HIDE_TAB_BAR").is_none() && …

To undo it, delete ~/.local/share/sidra/herdr-client. herdr is open source under the Apache 2.0 license.
